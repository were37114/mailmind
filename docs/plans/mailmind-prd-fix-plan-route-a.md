## 修复任务清单

### 🔴 Tier 1: Security 致命级修复（优先级最高）

#### T1-1: 本地数据加密方案（1.5天）
**目标**: PRD 第14章补充完整本地数据加密设计
**内容**:
- 数据分类分级（原始邮件 .eml / 结构化数据 / 向量索引 / 模型缓存）
- 加密算法：AES-256-GCM（数据加密）+ Argon2id（密钥派生）
- 密钥管理：用户密码派生主密钥 → 主密钥加密数据密钥 → 数据密钥加密实际数据
- 加密范围：哪些数据必须加密、哪些可明文（如分类标签等元数据）
- 设备丢失场景：无密码无法解密任何数据
- 密码重置策略：数据不可恢复（零知识架构）

#### T1-2: 云端增强安全架构（1.5天）
**目标**: PRD 新增独立章节 "云端增强安全规范"
**内容**:
- 传输层：TLS 1.3 + 证书固定（pinning）
- 端到端加密：用户端加密 → 服务端零持久化 → 解密在客户端
- 脱敏传输协议：L3脱敏后才可上传，上传内容展示给用户确认
- 授权机制：OAuth 2.0 + PKCE，短期访问令牌（1小时）+ 刷新令牌
- 服务端承诺：零数据持久化（处理完立即删除）、地域限制（中国境内）、第三方API披露
- 用户控制：一键关闭云端通道、查看所有上传历史、删除云端痕迹

#### T1-3: 合规框架实质性重写（1天）
**目标**: PRD 第14.2节从表面文字改为可执行的合规检查清单
**内容**:
- 等保2.0 第三级：逐项对应安全通信、边界防护、身份鉴别、数据保密性、安全审计
- 个保法：单独同意机制（非默认勾选）、最小必要原则、用户撤回同意
- GDPR：数据处理协议（DPA）、数据保护官（DPO）联络、跨境传输限制
- 合规验证：每个法规附 "如何验证合规" 的测试方法

### 🟠 Tier 2: QA 高风险修复

#### T2-1: 测试数据集扩展计划（0.5天）
**目标**: PRD 第7章 Phase 0 修改测试数据要求
**变更**:
- 200封 → 分层抽样 2000-4000 封
- 审批邮件专项集：≥400 封（用于验证98%召回率）
- 每类邮件 ≥50 封（5类分类验证）
- 数据来源：真实脱敏邮件优先，Enron公开数据集补充
- 数据版本管理：标注版本号、更新日志

#### T2-2: Ground Truth 标注协议（0.5天）
**目标**: PRD 新增 "测试协议" 附录
**内容**:
- 标注人员：2名标注员 + 1名仲裁员
- 标注一致性要求：Cohen's Kappa ≥ 0.8
- "审批邮件"定义标准：明确什么算审批（仅批复？包含转发待阅？）
- "事实"定义：邮件中可验证的陈述（日期、金额、人名、事件状态）
- 准确率公式：模型生成的正确事实数 / 模型生成的总事实数
- 测试集：20份周报，每份≥20个事实陈述

#### T2-3: 点击率统计验证方案（0.5天）
**目标**: PRD 补充 Beta 测试实验设计
**内容**:
- 所需样本量：2200 次展示（α=0.05, power=0.8, 20% vs 15%）
- Beta 用户规模：50 人 × 7 天 × 3 次/天 = 1050 次 → 需要 100 人或 14 天
- 对照组设计：随机推荐 vs 智能推荐 A/B 测试
- "点击"定义：点开卡片并停留 >3 秒

#### T2-4: 回归测试策略（0.5天）
**目标**: PRD 新增 "测试策略" 章节
**内容**:
- 单元测试覆盖率目标：≥70%
- 模型更新回归：每次模型版本更换必须重跑全量验收测试
- 性能回归：每次代码提交检查核心延迟指标（分类<500ms、周报<30s）
- 端到端测试：关键用户流程自动化（审批闭环、周报生成）
- CI/CD 集成：GitHub Actions 运行测试套件

### 🟡 Tier 3: ENG/CEO 中风险修复

#### T3-1: 7B 内存数据修正（0.5天）
**目标**: PRD 第13章硬件矩阵修正
**变更**:
- 7B Q4_K_M：权重 4.5GB → 运行时 6.5-7GB（含 KV Cache）
- 16GB 机器：标记为 "基础功能"（0.5B + 规则），不推荐运行 7B
- 32GB 机器：标记为 "全功能"（含 7B）
- 新增 "推荐配"：24GB RAM 或 16GB RAM + 8GB VRAM GPU

#### T3-2: PGLite 压力测试计划（0.5天）
**目标**: PRD Phase 0 W1 增加压力测试
**内容**:
- W1 验证项增加：PGLite 5万/10万邮件插入性能
- 向量索引构建时间测试（HNSW, 768维, 10万向量）
- WASM 内存占用监控（4GB 限制边界）
- 查询延迟测试（语义搜索 Top-5 延迟）
- 失败标准：索引构建 >10分钟 或 查询 >2秒 → 降级 SQLite + sqlite-vec

#### T3-3: 收入预测模型（0.5天）
**目标**: PRD 第8章补充收入预测
**内容**:
- 12个月三档预测（乐观/中性/悲观）
- 关键假设：专业版付费转化率 2-5%、企业版 1-3%
- CAC 假设：社区版自然增长 + 内容营销
- 盈亏平衡点：中性情况下约 800 专业版用户
